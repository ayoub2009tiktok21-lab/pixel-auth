# IRONLINE — Tactical FPS for Android (4v4)

لعبة تصويب من منظور الشخص الأول **أصلية 100%** — 4 ضد 4، جولات حتى 5 نقاط، مصممة للتحكم باللمس على الهواتف.
كل النماذج، الخرائط، الخامات والأصوات **مولدة إجرائيًا داخل اللعبة** (لا توجد أي أصول خارجية أو منسوخة).

**A 100% original first-person shooter** — 4v4, rounds to 5, touch controls designed for phones.
All models, maps, materials and audio are **procedurally generated in-code** (no external or copied assets).

---

## اللعب / Play

- **Web (فوري):** `cd game && node tools/serve.mjs` ثم افتح `http://localhost:8080`
- **Android:** ثبّت `APK/IRONLINE-v1.0.apk` (يتطلب Android 7.0+). الوضع الأفقي إلزامي، شاشة كاملة.

### التحكم (لمس)
| عنصر | الوظيفة |
|---|---|
| عصا يسار | حركة (دقة 0..1 مع منحنى استجابة) — إكمال النطاق = جري |
| سحب يمين | تصويب الكاميرا (حساسية قابلة للضبط + منحنى دقة + gyroscope اختياري) |
| FIRE | إطلاق (AK-47 تلقائي بالمسك المستمر، المسدس نصف تلقائي) |
| ADS | التصويب — FOV 72→50، انتشار أقل، وضعية سلاح مختلفة |
| JMP | قفز |
| CRCH | انحناء — أثناء الجري = **Slide** (ينتهي تلقائيًا في وضع الانحناء) |
| RLD / SWP | إعادة تلقيم / تبديل السلاح |
| ‖‖ | إيقاف مؤقت |

### التحكم (حاسوب للاختبار)
WASD حركة · فئرة/سحب يمين كاميرا · F إطلاق · E تصويب · مسافة قفز · C انحناء/انزلاق · R تلقيم · Q تبديل · P إيقاف.

## الأسلحة

| | AK-47 | M9-12 (مسدس) |
|---|---|---|
| ضرر جسم / رأس | 34 / 78 | 26 / 55 |
| معدل | 600 rpm تلقائي | 430 rpm نصف تلقائي |
| مخزن/احتياطي | 30/90 | 15/45 |
| تلقيم | 2.3s | 1.55s |
| ارتداد | نمط 12 طلقة (صعودي مع تمايل يمين/يسار + jitter) يتراكم مع السلسلة؛ يقل 38% مع ADS، 15% مع الانحناء | أصغر وأقصر |

ارتداد الكاميرا = نابض مستقل (spring) يُطبَّق فوق زوايا اللاعب — تعويضه بالسحب طبيعي تمامًا.

## الذكاء الاصطناعي
- **لا رادار**: الإدراك = خط رؤية حقيقي (raycast على نفس الـ collision) + مجال رؤية + مسافة + حركة الهدف + **سمع** (طلقة/خطوات).
- آخر موقع معروف → بحث (يذهب للـ LKP، يفحص الزوايا، يستخدم الغطاء، يستسلم بعد 16s).
- غطاء حقيقي: نقاط cover مُشتقة من هندسة الخريطة؛ يتراجع الجريح، يعيد التلقيم خلف الغطاء.
- **AI ضد AI كامل**: الزملاء يقتلون الأعداء والعكس؛ اللاعب قد يموت دون أن يكون الهدف.
- دقة بشرية: خطأ تصويب يتسع مع المسافة وحركة الهدف، فرص رأس محدودة (3–13%)، رشقات 2–9 طلقات مع فواصل.
- مستويات: Easy/Normal/Hard/Expert — تغيّر زمن رد الفعل، الخطأ، استخدام الغطاء والبحث (وليس "إصابة تلقائية").

## الخريطة — Kharan Crossing (128×128م)
طريقان متقاطعان، 11 مبنى بأبواب/نوافذ حقيقية (collision يطابق الشكل تمامًا)، برج مراقبة مقفاه بسلالم، برج ماء، أكياس رمل، صخور وأشجار متنوعة (3 أنواع × مقاييس/دوران عشوائي)، أسواق، موالد. **لا جدران وهمية**: كل ما تراه يحجب الرصاص والرؤية.

## الأداء
- جودة Low/Medium/High/Ultra (ظلال، دقة، جسيمات، AA).
- FPS Cap: 30/60/90/120 مع **كشف معدل الشاشة الفعلي** — العداد يعرض الـ FPS الحقيقي المقاس (لا أرقام وهمية).
- **Dynamic resolution**: يخفض دقة التصيير تلقائيًا عند هبوط الـ FPS ويرفعها عند الاستقرار.
- نظام جسيمات pooled (tracers/flashes/sparks/dust/decals) بميزانية حسب الجودة.

## الاختبارات (تمت فعليًا)
- **66 فحص آلي** في Node (منطق كامل بلا GPU): `cd game && node test/node/run.js`
  — حركة (مشي/جري/انحناء/انزلاق/قفز)، تصادم الجدران مع المشي والرصاص، إطلاق/ذخيرة/ارتداد/تعافٍ، ADS، تلقيم، تبديل، **عدم رؤية AI عبر الجدران** + سماع الطلقة والبحث عنها، AI ضد AI، أول فريق يصل 5 يفوز، إعادة المباراة، حفظ الإعدادات، أداء المنطق (~7600 تحديث/ثانية على VM بـ2 نواة)، 3 مباريات متتالية بلا تسريب كائنات.
- **اختبار بصري** في Chromium headless (WebGL): `cd game && node test/browser/shot.js` (لقطات + أخطاء الصفحة) — `game/shots/`.
- **بناء APK**: `node game/tools/apk/build.mjs` → `APK/IRONLINE-v1.0.apk` (موثّق: `apksigner verify` v2/v3، `aapt dump` يعرض معرفات android الصحيحة).

## ملاحظات تقنية
- القشرة Android: WebView أفقية كاملة مع جسر JS (اهتزاز، زر رجوع)، `FLAG_KEEP_SCREEN_ON`.
- كل شيء يعمل من `file:///android_asset` — لا إنترنت مطلوب.
- الإعدادات (حساسية/HUD/جودة/صوت/gyro) تُحفظ في `localStorage` وتبقى بعد إغلاق اللعبة.
